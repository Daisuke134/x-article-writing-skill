# x-article-writing skill

An agent skill for writing X Articles (long-form posts on X). It turns what current top articles do into one checklist: a title with a real number and a twist, a hard-fact first line, short paragraphs, credited sources, one visual block, a failure section, a specific reply question, a teaser post, and a required humanizer pass.

Real numbers only. If something is unmeasured, the skill makes you say so.

## Use

Copy `SKILL.md` into your agent's skills folder (for example `.claude/skills/x-article-writing/SKILL.md`, or your agent's equivalent) and ask it to write or review an X Article.
